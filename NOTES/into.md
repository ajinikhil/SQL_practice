# What is SQL?


## What is a database?

A database is a collection of data.

* Structure: Allows for efficient data storage, retrieval , and management
* Types of databases: Includes relational databases (organized in tables)  and non-relational databases (for unstructured data)

### Non-relational databases

Commonly known as `NoSQL` (Not Only SQL)
NoSQL databases supports unstructured data such as
* Key-value pairs
* Graph based
* Document based
* Column based

`Note:` An excel file can hold ~ 1million Rows. A database can hold millions of excel file.

## What is a query?

A Query is a request for data from a database, allowing us to perform various operations:

* Operations: Includes creating, reading, Updating and Deleting data (CRUD)

## What is Fact Tables

* Fact table contains core data for business analysis
* Measure and record business events (e.g., job postings)

## What is Dimention Tables

* Dimention tables describe attributes or dimentions of the data (e.g., skills, companies)
* It supports filtering, grouping, and labelling of facts in reports. 

## What is SQLite

It is a:

- Lightweight, file-based database
- Ideal for small to medium applications
- zero configuration; easy setup 

## What is Postgress

It is an:

- Advanced, opensource relational database
- Suited for large applications
- Supports complex queries, transactions
